# Hargus API Backend

This backend is a FastAPI scaffold that mirrors the current frontend domain and provides a clean place to attach Temporal-based AI workflows later.

## Included

- mock-backed vacancies and candidates endpoints
- AI task endpoint that creates async task records
- Temporal workflow and activity stubs
- `uv` project metadata
- pytest smoke tests

## Not Included Yet

- persistent database storage
- object storage for files
- authentication / RBAC
- real AI pipelines
- production Temporal deployment wiring
