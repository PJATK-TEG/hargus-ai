# Local Development

Generated by the coding agent to make local setup repeatable.

## Prerequisites

This machine currently has Docker installed, but not Python, `uv`, or `task`.

Recommended installs on Windows:

1. Install Python 3.11 or 3.12.
2. Install `uv`:
   - PowerShell: `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
3. Install Task:
   - `winget install Task.Task`

## Frontend

```powershell
cd frontend
npm install
npm run dev
```

Frontend URL:

- `http://localhost:3000`

## Backend

```powershell
uv sync --project backend --group dev
uv run --project backend uvicorn hargus_api.main:app --app-dir backend/src --reload --host 0.0.0.0 --port 8000
```

Backend URL:

- `http://localhost:8000`
- Swagger UI: `http://localhost:8000/docs`

## Worker

The worker is only needed once you want the API to actually connect to Temporal:

```powershell
uv run --project backend python -m hargus_api.worker
```

## Taskfile Shortcuts

Once `task` is installed:

```powershell
task frontend:dev
task backend:install
task backend:dev
task backend:test
task docker:build:api
task docker:up
```

## Temporal Stub Mode

By default, the backend runs with:

- `HARGUS_TEMPORAL_ENABLED=false`

That means:

- AI task requests still succeed
- a stub task record is created
- no external Temporal server is required yet

When you are ready to wire your actual workflow, set:

```env
HARGUS_TEMPORAL_ENABLED=true
HARGUS_TEMPORAL_SERVER_URL=<your temporal host>:7233
```
