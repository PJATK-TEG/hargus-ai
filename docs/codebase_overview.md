# Codebase Overview

Generated by the coding agent as a quick-ingest document for future contributors and LLM workflows.

## Current Shape

- `frontend/`: React + Vite + TypeScript dashboard prototype with mock candidate data.
- `backend/`: new FastAPI scaffold with mock-backed endpoints and Temporal-ready AI task stubs.
- `docs/`: architecture diagrams plus overview docs like this one.
- `Taskfile.yml`: common repo tasks for frontend, backend, and Docker flows.
- `docker-compose.yml`: minimal local Docker entry point for the API container.

## Product Model

The repo centers on a recruiting workflow:

- Vacancies
- Candidates
- Candidate files such as CVs, transcripts, notes, and background checks
- AI tasks that will eventually run ingestion, analysis, comparison, or red-flag workflows

The frontend currently renders mock data, but the backend now exposes matching REST contracts so the UI can be moved off static fixtures incrementally.

## Backend Snapshot

The backend is designed as a thin API gateway plus workflow launcher:

- `GET /api/v1/health`
- `GET /api/v1/vacancies`
- `GET /api/v1/vacancies/{vacancy_id}`
- `GET /api/v1/candidates`
- `GET /api/v1/candidates/{candidate_id}`
- `GET /api/v1/candidates/{candidate_id}/messages`
- `POST /api/v1/ai/tasks`
- `GET /api/v1/ai/tasks/{task_id}`

`POST /api/v1/ai/tasks` currently stores a stub task record and, when Temporal is enabled, starts a placeholder workflow instead of embedding any real AI logic in the request path.

## Tooling Direction
